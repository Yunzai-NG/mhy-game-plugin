# 角色面板

## 先取数，再看图

面板不会自己更新，看图之前先取一次。取数有两条路：

| 命令 | 走哪条路 | 代价 |
| --- | --- | --- |
| `#更新面板` | 绑了 CK 走米游社，否则走展柜（主人可在配置里改） | 见下两行 |
| `#展柜更新面板` | 展柜（Enka、MiniGG 等面板服务） | 不要 CK，但只看得见游戏里摆进角色展柜的那几个 |
| `#米游社更新面板` | 米游社 | 拿得到全部角色，用你自己的 CK、占查询额度；圣遗物词条档位由最终值反推，是近似值 |

取到之后，下面这些都读本地那一份，不再发请求。更新完回的就是面板列表图，所有角色在同一个框里，靠头像外框的光区分：

| 外框 | 意思 | 排在 |
| --- | --- | --- |
| 橙光 | 这次取到、且数据有变（含第一次取到的角色） | 最前 |
| 绿光 | 这次取到、但和上次一样 | 中间 |
| 无光 | 这次没取到，图上是上一次存的那份 | 最后 |

每一块内按角色 id 排。命座 / 星魂 / 影画印在名字左边，评分档位在头像右上角。

## 看图

| 命令 | 内容 |
| --- | --- |
| `#面板` | 名下已有面板的角色一览 |
| `#胡桃面板` | 单个角色的属性、装备与评分 |
| `#胡桃圣遗物` | 逐件评分与这个角色的权重；不带名字的 `#圣遗物` 看评分最高的若干件 |
| `#胡桃伤害` | 期望伤害与词条收益对比；一个角色有几套算法时 `#胡桃伤害2` 看第二套 |
| `#练度统计` | 全部角色的等级、天赋与武器一张表，也认 `#天赋统计` |
| `#胡桃` | 角色卡片：立绘配武器、天赋与套装；也可 `#我的胡桃` |

## 换装试算

三个游戏都可以算「换了会怎样」，算完只出这一张图，一律不写回你的面板、也不进排行：

| 写法 | 例子 |
| --- | --- |
| 借自己另一个角色的武器或整套圣遗物 | `#胡桃换钟离武器`、`#胡桃换刻晴圣遗物` |
| 只借某几个部位 | `#胡桃换刻晴花+杯` |
| 借别的 uid 名下某个角色的某一件 | `#胡桃换100000001夜兰杯`（那个 uid 要在你本人名下有过面板） |
| 换一件指定的武器或套装 | `#胡桃换5精90级护摩之杖`、`#胡桃换深林的记忆+宗室之翎` |
| 改等级、命座、天赋 | `#胡桃换80级`、`#胡桃换2命`、`#刻晴伤害换满行迹` |
| 换完直接看伤害或圣遗物 | `#胡桃伤害换满命`、`#胡桃圣遗物换深林` |

几段可以连着写：`#胡桃换钟离武器换刻晴圣遗物`。「换」也可以写成「变」「改」。借不到的部件只提一句，其余照常算。

开了伤害计算时，伤害表每格数字旁印出与原面板相比的增减：多了标红、少了标绿，没变或算不出的不印。比的是同名的那一行，换了命座多出来的新行没有可比对象，也不印。

## 本地数据

| 命令 | 作用 |
| --- | --- |
| `#刷新天赋` | 逐角色补一次天赋等级，练度统计才印得出；星穹铁道是 `*刷新行迹`，要自己的 CK |

## 自定义立绘

面板图的背景立绘可以换成主人上传的图：

| 命令 | 作用 |
| --- | --- |
| `#上传胡桃面板图` | 随消息带图上传（仅主人） |
| `#胡桃面板图列表` | 按序号列出这个角色已有的面板图 |
| `#删除胡桃面板图1` | 按序号删一张（仅主人） |
| `#胡桃图片` | 随机发一张这个角色的面板图 |
| `#原图` | 回复一张面板图或角色卡片再发，取那张图的原始立绘 |

- 满命、评分到 ACE / MAX 或天赋全满的角色，另从彩蛋图里挑。主人关掉「使用自定义面板插图」后一律用官方立绘。
- `#原图` 发的是立绘素材本身，不是渲染出来那张图。索引只留三小时；要平台既回消息 id、又在引用里带消息 id，缺一时只会回「认不出你回复的是哪张图」。

## 老婆

原神与星穹铁道可以从名下角色里挑一位出卡片：

- `#老婆`：随机挑一位
- `#老婆设置胡桃`：钉住这一位，原神与星铁分开存
- `#老婆是谁`：看钉住的是谁

也认「老公」「女儿」「儿子」等说法。只从名下已有面板的角色里挑，没有可挑的时候先 `#更新面板`。

## 伤害计算

伤害一栏缺省关闭，由主人在配置里打开「开启伤害计算」（`enableDmgCalc`）。开了之后 `#胡桃伤害` 出期望伤害与词条收益对比：哪条副词条多一档，伤害能涨多少。

<QQTabs :tabs="[
  { game: 'gs', msgs: [{ me: true, text: '#胡桃伤害' }, { img: 'panel/dmg', alt: '胡桃的伤害计算与词条收益' }] },
  { game: 'sr', msgs: [{ me: true, text: '*希儿伤害' }, { img: 'panel/dmg-sr', alt: '希儿的伤害计算与词条收益' }] },
  { game: 'zzz', msgs: [{ me: true, text: '%艾莲伤害' }, { img: 'panel/dmg-zzz', alt: '艾莲的伤害计算与词条收益' }] }
]" />

伤害公式是元数据里的 `calc.js`，是代码而不是数据，开启即意味着执行下载来的代码。插件在 `node:vm` 中求值：没有 require / process / fs、有超时、只认 `calc.js` 与 `artis.js` 两种文件名、来源锁定且增量包逐个校验 sha256。但 `node:vm` 不是硬安全边界，所以缺省关。

公式文件恒随元数据落盘（关着时只被解析、读静态加成，不执行），开关改完即生效，不必重下元数据。
