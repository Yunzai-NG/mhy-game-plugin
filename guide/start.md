# 快速上手

本页写给机器人的使用者。要在自己的实例上装插件，先看 [部署](../deploy/)。

## 前缀决定游戏

三个游戏共用一套命令，只是开头的记号不同：

::: code-group

```text [原神]
#体力
#胡桃面板
#帮助
```

```text [星穹铁道]
*体力
*青雀面板
*帮助
```

```text [绝区零]
%体力
%安比面板
%帮助
```

:::

星穹铁道也可以写 `#星铁体力`，绝区零也可以写 `#绝区零体力`。本站后文的例子一律用原神的 `#`，换成另两个游戏时把记号换掉即可。

## 三步上手

::: tip 本站的对话与截图
对话里每一张图都是插件真跑出来的，账号、uid、昵称与练度是编的演示数据，与任何真实账号无关。点图可以看原图。
:::

### 1. 扫码登录

发 `#扫码登录`，用米游社 App 扫图上的码，再在手机上点确认，一步绑好账号。群里也能扫，认准图上的标识码是发给你的那一张。

### 3. 看全部命令

发 `#帮助`。帮助图只列当前游戏、当前配置下真能用的那些，主人关掉的功能不会出现，图底会写「另有 N 项已被主人关闭」。

  { img: 'start/help', alt: '原神的主帮助图' }
]" />

主人发 `#帮助` 时多出「主人」与「群管理」两块；`*帮助`、`%帮助` 出的是另两个游戏那一版。

想看角色面板，再发一次 `#更新面板`，见 [角色面板](./panel)。

## 只想看看，不想给账号

可以只绑 uid：`#绑定uid100000001`。不给任何凭据，能用的是展柜里的角色面板、贴链接取抽卡记录、图鉴与日历。体力、札记、深渊一类要你本人的 CK，见 [绑定账号](./account)。

## 细分帮助

主帮助只列命令，下面几张讲先后与取舍：

| 命令 | 内容 |
| --- | --- |
| `#绑定帮助` | uid 与 CK 的区别、扫码、多个 uid、设备 |
| `#CK帮助` | 手动取 Cookie 的步骤 |
| `#面板帮助` | 两条取数路的取舍、看图、换装试算、本地数据 |
| `#排行帮助` | 四个维度怎么算、怎么入榜 |
| `#抽卡帮助` | 取记录、看图、导入与导出 |
| `#攻略帮助` | 有哪些攻略组、当前选了哪些 |
