# 抽卡记录

本地一条记录都没有时什么都看不了，先把记录取下来。

## 取记录

| 情况 | 怎么做 |
| --- | --- |
| 扫码登录过 | 直接发 `#更新抽卡记录`，凭 stoken 自助换取链接，群里也能用 |
| 没扫码登录过 | 私聊发 `#抽卡链接`，把游戏里「祈愿记录」的链接整条发来 |

星穹铁道是「跃迁记录」，绝区零是「调频记录」。

::: warning 链接只在私聊
链接里的 authkey 能读你的全部抽卡历史，群里发等于公开，命令层会直接拒收。
:::

每次更新按卡池报新增了多少条。不想再更新了，`#删除抽卡链接` 只删链接凭据，记录保留。

| --- | --- |
| `#抽卡记录` | 出金时间轴：每一发用了多少抽、歪没歪 |
| `#抽卡分析` | 同一张图，归在主人的「抽卡分析与统计」开关下 |

| 游戏 | 写法 |
| --- | --- |

| 绝区零 | `%音擎记录`、`%邦布记录`、`%音擎统计` |

## 导入与导出

都只在私聊受理。

### 导入

私聊发 `#抽卡导入`，60 秒内把 json 文件作为下一条消息发来；或者先发文件，再回复那条文件消息发 `#抽卡导入`。uid 取自文件，会顺带绑好。

<QQChat game="gs" :msgs="[
  { me: true, text: '#抽卡导入' },
  { text: '请在 60 秒内把 UIGF / SRGF 的 json 文件作为下一条消息发来' },
  { me: true, file: 'UIGF_demo.json' },
  { text: 'UIGF_demo.json 导入完成，uid 100000088\n角色活动祈愿：新增 597 条，共 597 条\n武器活动祈愿：新增 79 条，共 79 条\n常驻祈愿：新增 120 条，共 120 条\n合计新增 796 条，本地共 796 条' }
]" />

认三种格式：UIGF v4.0、UIGF v2.3（原神）、SRGF v1.0（星穹铁道）。

### 导出

| 命令 | 格式 |
| --- | --- |
| `#抽卡导出` | UIGF v4.0，一份文件可以装三个游戏 |
| `#抽卡导出v2` | 旧格式，给只认旧格式的工具用：原神 UIGF v2.3、星穹铁道 SRGF v1.0 |

### 合并规则

- 导入只合并、不覆盖：本地已有而文件里没有的记录一概保留。
- 去重按记录 id：先导入别人给的文件、再自己同步一次，不会重复。
- 本地库只增不减，长期使用后比米游社那半年的窗口更全。
