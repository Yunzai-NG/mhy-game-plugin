# 图鉴与资料

本页的命令不要 CK，但要主人装好元数据。元数据还没更新到的新角色认不出，请主人发 `#更新元数据`。

## 图鉴

| 命令 | 原神 | 星穹铁道 | 绝区零 |

| 图鉴 | `#胡桃图鉴` | `*青雀图鉴` | `%安比图鉴` |

- 图鉴不只查角色：武器、光锥、音擎、圣遗物 / 遗器 / 驱动盘套装、邦布都能查，如 `#护摩之杖图鉴`、`%云霓孤光图鉴`。套装可以用简称：`#魔女图鉴`。也认「资料」：`#胡桃资料`。

武器图鉴三个游戏同一种版式：左边立绘，右边满级属性与效果，五档精炼 / 叠影 / 星阶的数值高亮成一串。

### 未实装角色

元数据常在版本更新前就带上下一批原神角色。主人没关「允许查未实装角色」时，它们的图鉴、面板与排行照常可查，数据仅供参考。只影响原神。

## 攻略与素材

攻略与素材只有原神与星穹铁道，绝区零暂无来源。

| 命令 | 内容 |
| --- | --- |
| `#胡桃攻略` | 各攻略组做好的攻略图，合并转发 |
| `#胡桃更新攻略` | 忽略缓存重取索引与攻略图，也可写 `#更新胡桃攻略`（仅主人） |
| `#攻略帮助` | 有哪些攻略组、当前选了哪些 |
| `#设置攻略1,3` | 按序号挑用哪几家，`#设置攻略全部` 全选（仅主人） |
| `#胡桃素材` | 米游社合集里的一图流素材；`#胡桃更新素材` 重下 |
| `#胡桃图片` | 随机一张面板图，原神与星铁有 |

攻略索引缓存六小时，图下载后长期缓存。攻略组发了新攻略、或改了图而这边还是旧的，由主人发一次 `#胡桃更新攻略`。重取失败时仍用缓存里那份，不会把能看的攻略冲掉。

攻略图来自 gitee 上的攻略仓库，主人可以关掉「开启角色攻略」，关掉后 `#胡桃攻略` 不发请求、也不回话。

## 日历

`#日历`（也认 `#活动`）：未来十三天的活动、卡池与深渊轮换时间轴，原神另加角色生日与今日天赋书。`#日历列表` 只列活动、不画日期。

三个游戏都有，绝区零写 `%日历`，排的是调频与限时活动（没有深渊轮换）。各游戏活动的剩余时间与进度条另见 `#活动日历`，在 [日常与战绩](./daily#账号概况)。

## 兑换码

| 命令 | 内容 |
| --- | --- |
| `#前瞻兑换码` | 当期前瞻直播发的兑换码，不要 CK；还没放出的也列出来并标明 |
| `#兑换码 XXXX` | 国际服网页兑换，一次最多五个，兑换到你本人 CK 所属的账号 |

国服没有网页兑换接口，`#兑换码` 对国服 uid 只回游戏内的兑换途径。
