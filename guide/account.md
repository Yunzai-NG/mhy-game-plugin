# 绑定账号

## uid 与 CK

要查的东西决定你需要哪一个：

| 绑了什么 | 能查什么 |
| --- | --- |
| 只绑 uid | 展柜里的角色面板、贴链接取抽卡记录、图鉴与日历 |
| 绑了自己的 CK | 另加体力、札记、深渊与各类战绩、名下全部角色的面板、签到 |

::: tip 只绑 uid 查不了深渊
战绩、便笺这类米游社接口只能用你本人绑定、且覆盖这个 uid 的 CK 去查。只绑 uid 时它们一律回「没有可用的 CK」，原因见 [CK 只给本人用](#ck-只给本人用)。
:::

绑一次三个游戏通用，只是查询时前缀不同。

## 绑 CK

### 扫码登录（推荐）

发 `#扫码登录`，用米游社 App 扫图上的码。

- 一步取齐 CK 与 stoken。stoken 让后面几件事不必再贴凭据：CK 过期后 `#刷新ck` 自己换新、`#更新抽卡记录` 直接取记录、`#社区签到` 与 `#米游币`。
- 群里也能扫。码图上有标识，认准是发给你的那一张。

### 手动贴 Cookie

私聊发 `#绑定CK`，60 秒内把 Cookie 发过来；也可以直接 `#绑定CK` 后接 Cookie 一条发完。取法见 `#CK帮助`，浏览器里要执行的那行代码用 `#CK代码` 取。

<QQChat :msgs="[
  { me: true, text: '#绑定CK ltuid_v2=300000000; ltoken_v2=v2_……' },
  { text: '绑定成功，米游社账号 300****00\n原神：100000066\n星穹铁道：100000166\n绝区零：10000066\n已为该账号固定分配一台设备，此后每次请求均使用该设备。满一天后米游社会将其视为常用设备，验证码随之减少' }
]" />

一份 Cookie 绑上之后，名下三个游戏的 uid 一并认出来，不必逐个绑。

::: warning 只在私聊
Cookie 是凭据，群里发等于公开给所有人，命令层会直接拒收并提醒你撤回。那份 Cookie 已视为泄露，撤回后要重新取一份。
:::

`#刷新ck` 靠的是扫码登录取得的 stoken，手动贴的 CK 过期后要重新贴一次。

### 管理凭据

<QQChat :msgs="[
  { me: true, text: '#我的CK' },
  { text: '米游社 300****01\n　原神 100000088；星穹铁道 100000188；绝区零 10000088\n　绑定于 08-22 13:20' }
]" />

自己的 CK 只查自己，插件不限次数。CK 停用或被米游社限制当天查询时，会多一行说明原因。

| 命令 | 作用 |
| --- | --- |
| `#我的CK` | 名下几份凭据的状态与对应 uid，不印凭据本身 |
| `#刷新ck` | CK 失效后凭 stoken 换一份新的，扫码登录过才有 stoken |
| `#删除CK` | 删掉自己的 CK，已绑的 uid 不受影响；名下有几份时按列出的序号删，如 `#删除CK2` |

## 多个 uid

一个人可以绑好几个 uid，查询用当前那一个：

<QQChat :msgs="[
  { me: true, text: '#我的uid' },
  { img: 'account/uid', alt: '名下三个游戏的 uid 列表，当前那个有标记' }
]" />

| 命令 | 作用 |
| --- | --- |
| `#我的uid` | 列出名下全部 uid，当前那个有标记 |
| `#切换uid2` 或 `#uid2` | 按上一条列出的序号切换 |
| `#删除uid2` | 删掉某一个，不带序号删当前那个 |

面板与圣遗物可以在命令后加 uid 查别人的公开数据，如 `#面板100000001`。角色列表、练度统计与 `#信息` 也认命令后的 uid，但它们走 CK，只能查你自己 CK 名下的号（如同一米游社账号下的第二个号），不必先切换。

## CK 只给本人用

查 uid X 时，只用**发起者本人绑定、且覆盖 X** 的那份 CK：

- 不回落到你的其他 CK
- 没有公共池，别人的 CK 一概不借
- 绑了别人的 uid，也读不到他的私有数据

米游社的战绩接口不校验 CK 与 uid 的归属，这一条是防止越权读他人数据的唯一一道闸。

## 隐私

- 绑 CK、绑真机设备、贴抽卡链接、导入导出抽卡记录只在私聊受理。
- 日志里不出现 Cookie、stoken、authkey 与设备指纹。
- 抽卡记录按「使用者 + uid」分开存，绑了别人的 uid 也看不到他的抽卡历史。

## 设备

一般不用管。经常撞验证码时，可以换成自己手机的设备信息：

| 命令 | 作用 |
| --- | --- |
| `#设备信息` | 当前请求用的是系统分配的设备还是你绑的真机 |
| `#绑定设备` | 私聊提交手机上的设备信息，之后请求都用它 |
| `#解绑设备` | 回到系统分配的那台 |

`#绑定设备` 由主人在配置里决定是否开放（`allowBindDevice`，缺省开）。

### 取设备信息

1. 在手机上装 <a :href="withBase('/tools/copy_device_info.apk')" download>copy_device_info.apk</a>，打开后点开「设备信息」，再点「点击复制」。
2. 私聊机器人发 `#绑定设备`，把复制到的那段整段粘贴过去。

复制出来是一段 JSON，其中 oaid 用来标识这台手机，必须有；其余几项有几项发几项。也可以改发抓包所得的米游社请求头（`x-rpc-device_id` 等几项），抓包原文里的 Cookie 各行要先删掉。

::: warning OAID 全是 0
<img src="/help/oaid-zero.webp" alt="设备信息对话框里 OAID 一栏是一长串 0" width="320">

系统没给这个工具开「匿名设备标识符」时，OAID 就是一串 0。这样的值标识不了手机，`#绑定设备` 会拒收。

以 vivo 为例：设置 → 安全 → 更多安全设置 → 广告与隐私 → 匿名设备标识符管理，把 copy_device_info 那一项打开。其他品牌在「隐私」或「广告与隐私」里找同名开关。开了之后重新打开工具复制一次再发。

<img src="/help/oaid-switch.webp" alt="匿名设备标识符管理页，copy_device_info 一项的开关已打开" width="360">
:::
