# 签到

签到只用你**自己绑定**的 CK，别人名下的 CK 一概不动。

## 游戏福利签到

原神与星穹铁道可用，绝区零暂不支持。

| 命令 | 作用 |
| --- | --- |
| `#签到` | 当场签一次当前游戏，也认 `#米游社签到` |
| `#签到全部` | 名下两个游戏一起签 |
| `#自动签到` | 开启每天自动签到 |
| `#自动签到关闭` | 关掉 |
| `#签到状态` | 名下各账号的自动签到开关与上次结果 |

自动签到有两道开关：主人的总闸「每日自动签到总开关」（`enableAutoSign`，缺省关）与你自己按账号开的 `#自动签到`，两道都开才会执行。缺省每天 08:35 签，时间由主人配置。

主人的总闸没开时，`#自动签到` 照样记下你的开关，并明说眼下还不会真的执行。

签到时发现 Cookie 失效，会停用那一份 CK；撞上验证码时不过码、不重试，只告诉你去米游社手动点一次。

## 米游社社区签到

三个游戏都可用，要先 `#扫码登录`：用的凭据是扫码时取得的 stoken。

| 命令 | 作用 |
| --- | --- |
| `#社区签到` | 签米游社社区版块换米游币 |
| `#米游币` | 米游币余额与今日还能拿多少 |
