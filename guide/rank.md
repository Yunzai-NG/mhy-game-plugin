# 群排行

排行按群统计，私聊里没有排行。

## 四个维度

`#胡桃排行` 不带关键词时问的是**期望伤害**，不是圣遗物评分。分高却不是第一，多半是这个原因。

| 维度 | 写法 | 怎么算 |
| --- | --- | --- |
| 综合练度 | `#胡桃排行` | 这个角色的期望伤害；要主人开启「开启伤害计算」 |
| 圣遗物评分 | `#胡桃评分排行` | 圣遗物总评分 |
| 双爆副词条 | `#胡桃双爆排行` | 只数副词条里的双爆，暴击率按两倍计；主词条不计 |
| 加权有效词条 | `#胡桃词条排行` | 逐条副词条按这个角色的权重折算后累加 |

星穹铁道与绝区零的写法相同，把「圣遗物」换成「遗器」「驱动盘」。「排行」也可以写「排名」「榜」。

## 怎么入榜

排行随每次查看逐步累积，不是全量扫库：

1. `#更新面板`：取一次面板数据并入库
2. `#面板` 或 `#胡桃面板`：看过谁的面板谁才进榜，看一次列表交齐全部角色
3. `#刷新排名`：群管理按库里已有的面板重算本群，补齐缺的维度

不进榜的几种情况：

- 换装试算出的面板是假的，一律不进榜。
- 原神与星穹铁道的预设面板（uid 小于 100000006）不参与排名。
- 主人设了参与条件（`groupRankLimit`）时，不满足的不进榜，比如只收绑了 CK 的人。

## 怎么看

| 命令 | 内容 |
| --- | --- |
| `#胡桃排行` | 整条榜，缺省列前 15 名，名额由主人配置（`rankNumber`） |
| `#最强胡桃面板` | 直接出榜一那一位的面板；维度关键词同上，如 `#最强双爆胡桃面板` |

## 群管理

以下命令群管理与主人可用：

| 命令 | 作用 |
| --- | --- |
| `#关闭排名` | 本群不再记分、也查不了排行 |
| `#启用排名` | 恢复 |
| `#刷新排名` | 按库里已有的面板重算本群排行 |
| `#重置排名` | 清掉本群排行数据；`#重置排名胡桃` 只清这一个角色 |

主人另有一道总闸「允许群面板排行」（`enableGroupRank`），关掉后所有群都没有排行。
