# 缺省关闭的功能

缺省值的取向只有一条：**这件事是插件自己主动做的吗**。会代替使用者写入、会在使用者不知情时发请求、会引第三方来源的，一律缺省关；只读的查询开关一律缺省开。

## 缺省关的几项

| 配置项 | 开了会怎样 | 为什么缺省关 |
| --- | --- | --- |
| 开启伤害计算 `enableDmgCalc` | 面板显示伤害期望，`#胡桃伤害` 看词条收益，排行多出伤害那一维 | 执行下载来的代码 |
| 每日自动签到总开关 `enableAutoSign` | 每天按时代替使用者签到 | 唯一一项代替使用者写入的功能 |
| 体力提醒总开关 `enableStaminaRemind` | 体力过阈值时主动推一张便笺图 | 在使用者不知情时发请求、主动发消息 |
| 图鉴显示全服统计 `enableWikiStat` | 角色图鉴多四块统计，`#出场率` 可用 | 只有第三方来源 |
| 日历时间表打第三方补丁 `enableCalendarFix` | `#日历` 用人工校对的时间表覆盖 | 第三方来源 |
| 启动时自动下载元数据 `autoInstallMeta` | 首次启动自动装约 350MB | 下载时机应由主人决定 |
| 定时自动更新元数据 `enableMetaAutoUpdate` | 定时取增量包 | 插件自己主动发请求并写盘 |

### 伤害计算

伤害公式是元数据里的 `calc.js`，含条件分支，无法像其他元数据那样离线转成 JSON，开启即意味着执行下载来的代码。插件在 `node:vm` 中求值：

- 没有 require / process / fs，有超时
- 只求值 `calc.js` 与 `artis.js` 两种文件名
- 来源锁定官方仓库，增量包逐个校验 sha256

但 `node:vm` 不是硬安全边界，所以由你决定。关着时面板照常可用，只少伤害一栏；公式文件仍随元数据落盘，只被解析、读静态加成，不执行。开关改完即生效。

### 自动签到

两道开关都开才会执行：你的总闸，和每个使用者自己发的 `#自动签到`。只用使用者自己绑定的 Cookie；撞上验证码时不过码、不重试，只告知去米游社手动点一次。

签到时间由「自动签到时间」（`autoSignCron`）定，缺省 `0 35 8 * * *` 即每天 08:35。不建议改成整点或零分：那一刻全网的签到脚本都在打米游社，撞验证码的概率明显更高。

### 体力提醒

只为自己发过 `#体力提醒` 的使用者查，只用他本人的凭据。

- 后台轮询优先走米游社小组件那条接口：同样的账号与体力，但不吃验证码。小组件要 stoken，没扫码登录过、或同一游戏下绑了多个 uid 的账号退回实时便笺。
- 不按固定周期查：每次拿到回满秒数后推算大约几点到阈值，一个账号一天通常只查两三次。
- 使用者当场发 `#体力` 一律走实时便笺。

### 第三方统计与日历补丁

| 配置项 | 来源 | 请求里带什么 |
| --- | --- | --- |
| `enableWikiStat` | 原神：提瓦特小助手（api.lelaer.com）；星铁：ArkApi（ark.ivny.cn） | 只有角色名，结果缓存一小时 |
| `enableCalendarFix` | miao.games/api/calendar | 一个不带身份信息的 GET |

统计来自那两家的用户自主上传，非官方数据。日历补丁能决定日历上哪几条活动出现、起止画在哪。

## 缺省开、但会访问米哈游之外的服务

下面几项缺省开着，请求里都不带 Cookie。不需要时可以关掉或换成自建镜像：

| 配置项 | 访问谁 | 怎么关 |
| --- | --- | --- |
| 面板服务 `profileServer` / `srProfileServer` / `zzzProfileServer` | Enka、MiniGG、Mihomo 等展柜服务 | `panelUpdateByMys` 开着时，绑了 CK 的 uid 走米游社，不经过它们 |
| 头像索引 / 头像图 `pfpsHost` / `assetHost` | 插件自己的 Enka 镜像 | 换成自建镜像；清空则回落 Enka 官方 |
| 开启角色攻略 `enableCharStrategy` | gitee 上的攻略仓库 | 关掉后 `#胡桃攻略` 不发请求 |
| 元数据提交列表主机 `metaHost` | 元数据镜像 | 换成自建镜像 |

另有过码服务 `captchaService`，缺省留空、不走这条路。填了之后发给它的只有 uid 与米游社当场下发的两个公开验证串，Cookie、DS 与设备指纹一律不外发。协议见 [配置项 · 过码服务](../reference/config#过码服务)。

## 本插件不做的事

- 不把战绩连同 uid 送去任何第三方统计站，`#深渊` 只查不传。
- 不从公共池借 CK，查 uid X 只用发起者本人绑定、且覆盖 X 的那份。
- 日志里不出现 Cookie、stoken、authkey 与设备指纹。
