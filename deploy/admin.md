## 主人

### 元数据

| 命令 | 作用 |
| --- | --- |
| `#更新元数据` | 装 / 更新图标与资料，加「强制」重下完整包 |
| `#元数据状态` | 各游戏装到了哪个版本 |

详见 [安装与元数据](./#元数据)。

### CK

这里的「池」只是全部已绑定 CK 的列表，供主人看用量与清理。查询时不存在公共池，每个人只用自己的那份。

| 命令 | 作用 |
| --- | --- |
| `#用户统计` | 全部 CK 的可用、失效与今日用量 |
| `#CK池` | 逐条列出，ltuid 打码 |
| `#删除无效用户` | 删掉已停用的 CK 及其设备信息与签到记录 |
| `#刷新用户缓存` | 把误判停用的 CK 恢复可用，保留今日用量 |
| `#重置用户缓存` | 同上，另把今日用量与「米游社判当天到顶」的标记一并清掉 |

<QQChat :msgs="[

插件不限 CK 的查询次数：每份 CK 只给绑定者本人查自己，限了只会挡住自己。今日用量只作统计。米游社判定某个账号当天查询到顶时，插件当天不再用它，零点后恢复。

### 面板图

| 命令 | 作用 |
| --- | --- |
| `#上传胡桃面板图` | 随消息带图，或回复一张图再发 |
| `#胡桃面板图列表` | 按序号列出；关掉「允许查看面板图列表」后不再逐张发图 |
| `#删除胡桃面板图1` | 按序号删一张 |

上传与删除只限主人：它们要下载使用者给的任意地址并往磁盘写东西。

星穹铁道同一角色的不同命途（`三月七` 与 `三月七·巡猎`）缺省共用一个面板图目录，开拓者一律归到 `穹` / `星` 名下。

### 攻略

原神与星穹铁道可用：

| 命令 | 作用 |
| --- | --- |
| `#设置攻略1,3` | 按序号挑用哪几家攻略组，`#设置攻略全部` 全选；序号见 `#攻略帮助` |
| `#胡桃更新攻略` | 忽略缓存重取这个角色的索引与攻略图；重取失败时仍用缓存那份 |

攻略索引缓存六小时，图长期缓存。攻略组改了图时文件名会变，一般自然重下；没跟上时才用 `#胡桃更新攻略`。

## 群管理

群管理与主人可用，只对当前这个群生效。

### 排行

| 命令 | 作用 |
| --- | --- |
| `#关闭排名` / `#启用排名` | 本群不再记分、也查不了排行 / 恢复 |
| `#刷新排名` | 按库里已有的面板重算本群排行，补齐缺的维度 |
| `#重置排名` | 清掉本群排行数据；`#重置排名胡桃` 只清这一个角色 |

### 体力提醒

| 命令 | 作用 |
| --- | --- |
| `#体力提醒群关闭` | 在本群开过提醒的人都不再收到 |
| `#体力提醒群开启` | 恢复；各人仍要自己发一次 `#体力提醒` |

## 两道闸的功能

有几项功能主人一道、使用者或群管理另一道，两道都开才生效：

| 功能 | 主人的总闸 | 另一道 |
| --- | --- | --- |
| 群排行 | 允许群面板排行（`enableGroupRank`） | 群管理 `#关闭排名` |
| 自动签到 | 每日自动签到总开关（`enableAutoSign`） | 使用者 `#自动签到` |
| 体力提醒 | 体力提醒总开关（`enableStaminaRemind`） | 使用者 `#体力提醒`，群管理 `#体力提醒群关闭` |

## 数据放在哪

路径都相对实例目录：

| 路径 | 内容 |
| --- | --- |
| `config/mhy-game.yaml` | 配置 |
| `data/plugin/mhy-game/meta/` | 元数据，约 350MB |
| `data/plugin/mhy-game/gacha/` | 抽卡记录 |
| `data/plugin/mhy-game/panel-img/` | 上传的面板图 |
| `data/plugin/mhy-game/face/` | 玩家头像缓存 |
| `data/plugin/mhy-game/strategy/`、`material-img/` | 攻略图与素材图缓存 |
| 框架的 KV 库 | CK、uid 绑定、设备、面板、排行与签到状态 |

迁移实例时 `data/plugin/mhy-game/` 与框架的 KV 库都要带走。元数据可以不带，到新实例上重新 `#更新元数据`。
