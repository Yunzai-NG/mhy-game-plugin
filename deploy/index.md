# 安装与元数据

本页写给在自己实例上部署插件的主人。

## 安装

需要 Yunzai NG 内核 0.7.0 及以上。

推荐经面板的插件市场安装：面板 → 插件市场 → 搜索 `mhy-game-plugin` → 安装。

也可以手工克隆到实例的 `plugins/` 下再编译：

```powershell
cd <实例目录>\plugins
git clone https://github.com/Yunzai-NG/mhy-game-plugin.git
cd mhy-game-plugin
pnpm install
pnpm run build
```

::: warning 插件目录里不要另装 @yunzai-ng/core
它会遮蔽宿主那一份，表现是命令照常触发、而每一项配置都读成 undefined。仓库自带的 `.npmrc` 已关掉 `auto-install-peers`，照上面的步骤装不会出现这种情况。
:::

## 渲染器

查询结果默认以图片回复，需要先装 [renderer-puppeteer](https://github.com/Yunzai-NG/renderer-puppeteer)（或其他渲染器插件）。渲染器不可用或出图失败时退回文字，命令本身不会失败。

出图的清晰度由「渲染精度」（`renderScale`）调，缺省 100。调高会让图更清晰，但字节数明显变大，渲染与发送都更慢。

## 元数据

角色与武器的图标、简称、图鉴文案、面板计算用的曲线都来自元数据，三个游戏合计约 350MB，落在实例的 `data/plugin/mhy-game/meta/` 下。

插件本身不带任何随游戏版本变的数据，没装元数据时，依赖它的命令会明说「先发 #更新元数据」，不会出一张全是 0 的图。

### 第一次安装

装好插件后由主人发一次 `#更新元数据`。下载要几分钟，插件先回一条「已开始」，装完再回一条，期间不要重复发。

| 命令 | 作用 |
| --- | --- |
| `#更新元数据` | 三个游戏一起装或更新；已装过时只取增量包 |
| `*更新元数据`、`%更新元数据` | 只更新星穹铁道 / 绝区零；也可写 `#更新元数据星铁` |
| `#更新元数据强制` | 重下完整包；增量更新出错留下坏文件时用它 |
| `#元数据状态` | 各游戏装到了哪个版本 |

### 自动下载与定时更新

两项都缺省关，下载时机由主人决定：

| 配置项 | 作用 |
| --- | --- |
| 启动时自动下载元数据（`autoInstallMeta`） | 首次启动时自动装那几百兆 |
| 定时自动更新元数据（`enableMetaAutoUpdate`） | 按周期（缺省 12 小时）检查一次，有新提交就取增量包；只更新已装过的那一份 |

开了定时更新后，失败时缺省会私聊通知主人：首次失败立刻通知，之后最短隔 60 分钟再通知一次，成功一次即清零。

不开定时更新的话，新角色的图标与简称要等主人手动 `#更新元数据` 才认得出。

### 换源

元数据版本的查询地址是「元数据提交列表主机」（`metaHost`）。缺省源不可用时可以改成自建镜像。

## 配置

配置文件是实例目录下的 `config/mhy-game.yaml`，也可以在面板的「米哈游游戏」设置页里改，改完即生效。全部配置项见 [配置项](../reference/config)。

部署后建议先过一遍 [缺省关闭的功能](./privacy)，决定哪些要打开。
