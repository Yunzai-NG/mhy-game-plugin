# 命令一览

前缀决定游戏：原神 `#`、星穹铁道 `*`（或 `#星铁`）、绝区零 `%`（或 `#绝区零`）。表里的例子一律写原神的 `#`，换游戏时换掉记号；「游戏」一栏写「通用」的三个游戏都能用。

机器人里发 `#帮助` / `*帮助` / `%帮助` 出的是同一份目录的图片版，只列当前游戏、当前配置下真能用的那些。

标记：<Badge type="warning" text="私聊" /> 只在私聊受理，<Badge type="danger" text="主人" /> 仅主人，<Badge type="info" text="群管理" /> 群管理与主人，<Badge type="tip" text="需开启" /> 要主人先打开对应配置。

## 账号绑定

绑一次三个游戏通用。不绑 CK 只能看展柜面板、图鉴与抽卡链接。详见 [绑定账号](../guide/account)。

| 命令 | 游戏 | 说明 |
| --- | --- | --- |
| `#扫码登录` | 通用 | 米游社 App 扫码，一步取齐 CK 与 stoken，之后 CK 过期能自己续上 |
| `#绑定CK` <Badge type="warning" text="私聊" /> | 通用 | 手动贴 Cookie 绑定 |
| `#CK帮助` | 通用 | 手动取 Cookie 的步骤；`#CK代码` 取浏览器里要执行的那行代码 |
| `#绑定uid100000001` | 通用 | 只绑 uid，不给凭据；也可写 `#绑定100000001` |
| `#我的uid` | 通用 | 名下全部 uid，当前那个有标记 |
| `#切换uid2` | 通用 | 按序号切换，也可 `#uid2` |
| `#删除uid2` | 通用 | 删掉某一个，不带序号删当前那个 |
| `#我的CK` | 通用 | 自己那几份凭据的状态与对应 uid |
| `#刷新ck` | 通用 | CK 失效后凭 stoken 换一份新的，不必重绑 |
| `#删除CK` | 通用 | 删掉自己的 CK，uid 不受影响 |
| `#设备信息` | 通用 | 当前请求用的是哪台设备 |
| `#绑定设备` <Badge type="warning" text="私聊" /> | 通用 | 提交自己手机的设备信息，之后请求都用它 |
| `#解绑设备` | 通用 | 回到系统分配的那台 |

## 角色面板

| 命令 | 游戏 | 说明 |
| --- | --- | --- |
| `#更新面板` | 通用 | 取一次面板并入库；绑了 CK 走米游社拿全部角色，否则走展柜 |

| `#米游社更新面板` | 通用 | 指名走米游社：全部角色，占查询额度 |
| `#面板` | 通用 | 名下已有面板的角色一览；可加 uid |

## 群排行

排行按群统计。详见 [群排行](../guide/rank)。

| 命令 | 游戏 | 说明 |
| --- | --- | --- |
