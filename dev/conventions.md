# 测试与约定

## 注释

### 文件头

每个 `.ts` 与 `.test.ts` 开头都有四行固定字段：

```ts
/**
 * 模块职责：一句话说清这个文件干什么
 * 依赖方向：依赖谁、被谁依赖，有无 IO
 * 生命周期：无状态 / 每个用例一份新 KV / 随插件走……
 * 注意事项：判据与后果
 */
```

「注意事项」只写**改错了不报错**的那几处：判据是什么、写错的表现是什么，一句话说完。目标 8 行以内，超了多半是在复述代码。

### TSDoc

`src/` 下导出的函数、类、方法、interface、type、enum 及其属性都要有 TSDoc，由 eslint 的 `jsdoc/require-jsdoc` 强制。`@param` / `@returns` 要带描述、**不写类型**（`jsdoc/no-types`），类型由 TS 自己说。

### 不要写的

- 变更史、「先前如何、现已改为」。注释一律是第一次提交时的样子；旧写法若会被重新写回来，只写「那样写会怎样」。
- 其他插件的出处与对照、排错过程、bug 与修复记录。
- 同一件事在多处重复说明。挑一处写，别处引用（`见 meta/pool.ts 的文件头`）。
- 能由类型签名、函数名或紧邻的代码直接看出的事，如 `// 遍历列表`。

行内注释优先单行 `//`，紧贴被说明的那一行；块注释只在判据确实要几行才说得清时用。

## 测试

| 层 | 怎么测 |
| --- | --- |
| 命令 | 造一个假 `Session` 记下回复，配一份手写的 `MhyDeps`，直接调处理函数 |
| 视图 | 纯函数，喂合成的接口返回，逐字段断言 |
| 服务 | 假 `HttpClient`，`new Kv(new MemoryKvDriver())` 做 KV |
| 模板 | `render.test.ts` 真编译，`templates.test.ts` 静态体检 |
| 帮助 | `catalog.test.ts` 对账，见 [加一条命令](./command#帮助目录) |

- 每个用例一份新 KV、新临时目录，`afterEach` 里清掉。
- 夹具手写替身，不抄元数据原文；要真数据的那组读 `MHY_REAL_META`，见 [元数据 · 测试夹具](./meta#测试夹具)。
- 依赖「现在」的用例要钉住时刻。命令层取系统时间而夹具窗口是写死的日期，不钉则窗口一过期，这些用例就随真实日期自行失效。
- 静默分支要测「一句话都不说、也不发请求」，不只是「没出图」。

## 几处改错了不报错的地方

| 地方 | 写错的表现 |
| --- | --- |
| `cmdRe` 的正则体没用 `String.raw` | 那条命令再也触发不了 |
| 命令里写死 `#` 而不是 `SHORT_PREFIX[game]` | 星铁与绝区零的使用者照抄到一条发不出去的命令 |
| 接口 query 串的顺序 | DS 不对，接口回语义无关的错误码 |
| 设备在请求时即时生成 | 账号被判多设备，验证码成片出现 |
| 风控时换 CK 或停用 CK | 风控扩散到第二个账号，或一次验证码清空某人全部 CK |
| 视图的键与模板对不上 | 整张图出不来，命令永远只回文字 |
| 模板里用了 `String()` 一类全局对象 | 同上 |
| 元数据图片用了 `_res_path` | 一格空白 |
| 星铁与原神的元数据形态当成一样 | 不报错，只是查不到 |
